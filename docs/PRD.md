# glyph-punch 需求文档

> 把古诗文打成孔，被挖下的字变成纸片，用户在画板上拼贴成新的诗。

## 1. 定位

面向想创作拼贴诗的人的古诗文打孔器。用户导入一段古诗文，逐字打孔，字离开原文、变成纸片，在下方创作区重新拼贴；作品以 PNG 导出。

核心不是"背诵填空"，而是**以字为单位的二次创作**：约束来自原文（只能用被挖下的字），自由来自摆放（可以拼成任何句子）。

## 2. 用户与场景

- 主要用户：做视觉内容的人（小红书式图文创作者）、对古文字感兴趣的人。
- 典型动作：导入一首诗 → 挑十几个字打孔 → 在画板上摆成一句新的话 → 微调 → 导出。
- 使用环境：桌面浏览器，一次 5–20 分钟。

## 3. v1 范围

**做**

- 文本导入（粘贴，保留换行）
- 逐字点击打孔，洞留在原位
- 纸片进入创作区，自由拖拽摆放
- 一键对齐（行识别 + 基线对齐 + 行内均分 + 随机偏移）
- 纸片拖回原文区即回填原洞
- 3:4 / 1:1 / 9:16 画板
- 双色主题预设 + 自定义取色入口
- 本地自动保存、多作品列表、JSON 导出/导入
- 1x PNG 导出

**不做（明确推迟）**

- AI 按提示词自动挖字（v2）
- 内置诗文库（v1.1）
- 背景图（v1.1）
- 手机端（v1 之后）
- 分享链接、账号、云端
- 批量打孔（仅单字点击）
- 字体切换 UI（底层做成字体包注册表，只内置一款）

## 5. 数据模型

```ts
type RatioId = '3:4' | '1:1' | '9:16'
type AlignMode = 'left' | 'justify' | 'center' | 'right'

interface Work {
  id: string
  title: string
  text: string            // 原始文本，换行保留
  ratio: RatioId
  paletteId: string
  align: AlignMode
  punched: number[]       // 已打孔字符在 chars 数组中的下标
  tiles: Tile[]           // 创作区纸片
  updatedAt: number
}

interface Tile {
  charId: number          // 指向 chars 下标
  x: number               // 画板逻辑坐标（1080 宽基准）
  y: number
  rot: number             // 度
  z: number               // 层级
}
```

`chars = Array.from(text)`，换行也是其中一个字符，但不可打孔、不占纸片。

## 6. 排版规则

1. 文本按 `\n` 硬切行，每行独立；段内超宽则按字符数折行。
2. 字号：二分查找能同时满足「每行不超宽」和「总高不超区」的最大字号（6–96）。
3. 中文按等宽处理，每个字符占 1em；标点同宽。
4. 对齐：左对齐 / 两端对齐（行内均分）/ 居中 / 右对齐，逐字计算 x。
5. 打孔不改变排版：洞占据原字符的位置与宽度，文本不回流。
6. 原文区占画板上部（约 66%），创作区占下部（约 30%），中间留白。

## 7. 交互

- 点击原文中的字：字变洞，纸片以掉落动画进入创作区（默认按行排布）。
- 洞的形状带手作抖动：每张孔有独立的旋转（±3°）、偏移、尺寸与圆角，相邻孔可以互相压边，形成毛边而不是机器切口。抖动由作品 ID 定种子，刷新与导出结果一致。
- 拖动纸片：自由移动，限制在画板内。
- 拖进原文区松手：纸片回到它自己的洞。
- 「对齐」：重新分行、吸基线、均分，附加随机位移与旋转。
- 撤销 / 重做：所有破坏性操作入栈。
- 导出：当前画板 1:1 绘制到 Canvas 后下载。

## 8. 视觉

- 基调：暗色工作台中央一张被灯照亮的纸。
- 双色：纸色 + 撞色；原文区纸底墨字、洞为撞色；创作区撞色底、纸片为纸色。
- 字体：霞鹜文楷为默认（手写楷，起笔带锋），思源宋体为备选；两套均为自托管 woff2 子集，切换即时生效。
- 唯一致敬点：打孔瞬间纸片掉落。其余动效克制。
- 不依赖用户系统字体，保证不同机器导出观感一致。

## 版本策略

0.x 阶段（当前 0.2.0）：接口、本地存储格式、视觉都可能变动，每个小版本在 README 与 PRD 里记录改动。到 1.0 再冻结数据格式。

## 9. 里程碑

- **v1**：上面「做」的全部。
- **v1.1**：内置诗文库、背景图、更多主题、字体包切换 UI。
- **v2**：AI 挖字（提示词 → 选出要挖的字）、分享链接。

## 10. 已知风险

- **长文纸片过小**：纸片等于原文字号，导入《赤壁赋》这类长文时字号会被压到十几像素，纸片难以拖拽。缓解：画板按视口缩放、提高命中区；或 v1.1 提供「创作区独立字号」。
- **行列识别**：y 聚类对旋转纸片不稳定，需要按旋转角归一化后再聚类。
- **字体一致性**：系统宋体在不同 OS 上观感不同，导出结果不可控；字体包是最终解法。
